# Собственный клиент

Персональная модификация Android-клиента Telegram на основе [exteraless](https://github.com/exteraless/exteraless).

## Статус

Проект находится на этапе первичной настройки форка. Исходная кодовая база и её GPL-3.0 лицензия сохраняются. Это независимая сборка; она не является официальным приложением Telegram.

## Первые изменения

- отдельный Android application ID: `com.xradiuzz.sobstvennyclient`;
- название приложения: «Собственный клиент»;
- отдельное имя выходного APK;
- отдельный GitHub Actions workflow для ARM64 debug APK;
- сборка через GitHub Actions без Android Studio.

## Сборка APK

Откройте вкладку **Actions**, выберите **Собственный клиент — Android APK** и нажмите **Run workflow**. После успешной сборки APK будет доступен в Artifacts.

Workflow собирает `arm64-v8a` для современных 64-битных Android-устройств. Для сборки используются JDK 21, Android SDK/NDK, CMake и Python 3.11.

Для входа в Telegram приложение использует API ID и API hash, заданные в конфигурации сборки. Для личного распространения рекомендуется зарегистрировать собственные значения на https://my.telegram.org/ и передавать их через защищённую конфигурацию CI, а не публиковать в репозитории.

## Важное о Firebase

Файл Google Services адаптирован по package name для прохождения конфигурации Gradle, но это не создаёт отдельное Firebase-приложение. Для корректных push-уведомлений нужно зарегистрировать `com.xradiuzz.sobstvennyclient` в Firebase и заменить `TMessagesProj/google-services.json` собственным файлом.

## План развития

1. Добиться воспроизводимой ARM64-сборки и проверить установку рядом с Telegram.
2. Обновить фирменное оформление, тему и анимации.
3. Расширить настройки приватности и управления сообщениями.
4. Развивать плагины с сохранением модели разрешений exteraless.
5. Интегрировать музыкальный плеер и расширенные загрузки.
6. Добавлять ИИ-функции через настраиваемых провайдеров; ключи API хранить только локально.
