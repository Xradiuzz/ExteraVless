# ExteraRoflan

Самостоятельно развиваемая модификация Android-клиента Telegram на основе [Exteraless](https://github.com/exteraless/exteraless).

## Текущий этап

Сейчас проект проходит этап перехода от базового форка к полноценному фирменному клиенту. Одного изменения названия недостаточно: дальнейшая работа сосредоточена на собственной визуальной системе, интерфейсе, настройках оформления и уникальных функциях.

## Базовые параметры

- Название приложения: **ExteraRoflan**.
- Android application ID: `com.xradiuzz.sobstvennyclient` (не менять без отдельной необходимости).
- Основа: Exteraless.
- Автор форка: **@Xradiuzz**.
- Лицензия исходной кодовой базы: GPL-3.0; сохранять лицензионные уведомления и атрибуцию.
- Сборка: ARM64 debug APK через GitHub Actions, без необходимости устанавливать Android Studio на телефон.

## Направление развития

1. Единый фирменный стиль: иконка, логотип, палитра, типографика и графические ресурсы.
2. Полностью оформленный раздел ExteraVless в настройках.
3. Расширенные настройки внешнего вида чатов и списков.
4. Собственные удобные инструменты управления чатами и приватностью.
5. Проверка совместимости, производительности и стабильности на Android.

Базовые функции Telegram и совместимость с его сетью должны оставаться рабочими. Сетевой обход белых списков не является целью проекта.

## Сборка APK

Откройте вкладку **Actions**, выберите **ExteraRoflan — Android APK** и запустите workflow вручную (**Run workflow**). После успешной сборки скачайте артефакт **ExteraRoflan-ARM64-debug** и распакуйте ZIP.

Workflow собирает вариант `arm64-v8a` для современных 64-битных Android-устройств. Используются JDK 21, Android SDK/NDK, CMake и Python 3.11.

## Обои и темы

В разделе **ExteraVless → Оформление → Обои и темы чатов** открывается штатный менеджер Telegram для выбора тем и фонового изображения. Отдельные обои для конкретного диалога назначаются из меню соответствующего чата.

## Подпись и обновления

Workflow сохраняет debug signing key через GitHub Actions cache, чтобы последующие APK можно было устанавливать поверх предыдущих без удаления данных. Если ранее установленная сборка была подписана другим временным ключом, Android может отклонить первое обновление: одного увеличения versionCode в таком случае недостаточно.

## Важные замечания

Это независимая сборка на основе открытого проекта, а не официальное приложение Telegram. Для собственного распространения следует настроить собственные Telegram API credentials и Firebase-конфигурацию. Не публикуйте секретные ключи в репозитории.
